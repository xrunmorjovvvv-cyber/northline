# Northline Cut

Локальный генератор 14 вертикальных кадров для серии «Одна страница». Кадр идёт в TikTok, YouTube Shorts и Reels и ведёт на уже опубликованный набор.

Пост: https://boosty.to/lerash/posts/9724a49e-e3c5-41b1-9b84-ba365b37b59a

## Запуск

```bash
python generate.py
```

Нужен Pillow (`pip install -r requirements.txt`). На этой машине он уже стоит.

После запуска:

- `out/cards/01.png` … `14.png` — кадры 1080×1920
- `out/captions/01.txt` … `14.txt` — текст, который говоришь в ролике
- `out/posts/01.txt` … `14.txt` — название, подпись и первый комментарий
- `out/posts/00-порядок.txt` — порядок четырнадцати дней
- `out/index.html` — лента, чтобы просмотреть все кадры

Платные PDF в репозиторий не входят. В кадр попадает страница, цена и ссылка.

## Как снимать один ролик

1. Открой `out/cards/01.png` на телефоне или втором экране.
2. Проговори текст из `out/captions/01.txt`. Хватает 20–25 секунд.
3. В конце держи в кадре цену 590 ₽ и `boosty.to/lerash`.
4. Один и тот же файл выложи в TikTok, Shorts и Reels. Ссылку на пост положи первым комментарием.
